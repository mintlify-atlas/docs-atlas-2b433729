## Get Up and Running

<Steps>
  <Step title="Install Haxe and Git">
    Download [Haxe](https://haxe.org) and [Git](https://git-scm.com). You'll need both to clone the repo and compile the game.
  </Step>
  <Step title="Clone and set up the repository">
    ```bash
    git clone https://github.com/FunkinCrew/funkin.git
    cd funkin
    git submodule update --init --recursive
    ```
    Then install the Haxe library manager and all dependencies:
    ```bash
    haxelib --global install hmm
    haxelib --global run hmm setup
    hmm install
    haxelib run lime setup
    ```
  </Step>
  <Step title="Build for your platform">
    ```bash
    lime test windows    # Windows
    lime test mac        # macOS
    lime test linux      # Linux
    lime test html5      # Browser / HTML5
    ```
    See the [Compiling Guide](/compiling) for platform-specific prerequisites such as Visual Studio Build Tools on Windows.
  </Step>
  <Step title="Start modding or contributing">
    Install a mod by dropping its folder into the `mods/` directory next to the executable, or dive into [Contributing](/contributing/guide) to submit your first pull request.
  </Step>
</Steps>
